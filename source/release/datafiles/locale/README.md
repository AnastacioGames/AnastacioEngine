# Locale (subconjunto)

Origem: https://github.com/blender/blender-translations, branch `blender-v2.79-release`,
commit `1bbc9bdabe4ed26c164aef8a43ef39657dc23cfb` (GPL, licença própria do Blender; não altera a licença do projeto).

Subconjunto versionado: `po/pt_BR.po`, `po/pt.po`, `po/es.po` e `po/ru.po`. O arquivo `languages` foi reduzido a
Default, English, pt_BR, pt_PT, es e ru_RU (o original lista 30+ idiomas). Para adicionar outro idioma, copie o `.po`
do repositório acima para `po/` e a linha correspondente do `languages` original.
Os `.mo` são gerados pelo alvo `msgfmt` no build (source/creator/CMakeLists.txt).
