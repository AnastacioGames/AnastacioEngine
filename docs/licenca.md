# Licença

Os cabeçalhos do código herdado declaram **GNU GPL versão 2 ou, a critério do distribuidor, qualquer versão
posterior** (`GPL-2.0-or-later`). Por isso uma distribuição pode optar pela GPLv3, mas a documentação não
deve afirmar que todo o repositório é exclusivamente `GPL-3.0-only`.

- [`source/COPYING`](../source/COPYING) contém o aviso geral herdado.
- [`source/doc/license/GPL-license.txt`](../source/doc/license/GPL-license.txt) contém a GPLv2.
- [`source/doc/license/GPL3-license.txt`](../source/doc/license/GPL3-license.txt) contém a GPLv3.

Dependências, fontes e outros recursos de terceiros possuem avisos próprios nos respectivos diretórios.
Antes de publicar uma distribuição, escolha e declare de forma explícita a versão aplicável ao fork e
confira os avisos que precisam acompanhar o pacote. Este resumo não substitui os textos legais.

O conversor de DDS usa [rgbcx](../source/extern/rgbcx/README.anastacio.md), sob a alternativa MIT.
O aviso [rgbcx-license.txt](../source/release/text/rgbcx-license.txt) acompanha a instala??o e o export de runtime.
